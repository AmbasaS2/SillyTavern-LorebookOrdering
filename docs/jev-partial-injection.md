# Experimental partial injection
     
Off by default; independently enabled in advanced Jev settings. Only long, explicit Timeline/Scene/Result memories with complete inputs and a built-in selection prompt can be offered. Custom prompts, reading limits, ambiguous structure, macro/decorator text, constants, protected or non-eligible entries keep the previous behavior. No stored book, UID, flag or prompt change.
     
A separate excerpt-safety choice question is placed in an existing Jev batch only if its full source and instructions fit the existing request and per-question limits. Binary inclusion and its score are untouched; independent questions cannot depend on each other's answers. The shared format instruction is extended only for batches that contain optional questions. Question choice and probability must be valid and probability >=0.85; otherwise retain the full entry. This threshold is a conservative experimental engineering choice, not measured accuracy. Each allowed extract is deterministic original paragraphs (setup, ending, Timeline, Result, explicit durable/critical cues, and a local window); no paraphrasing or arbitrary cut. Missing gaps are marked. No extra network request or batch for excerpts; a provider size rejection retries the unchanged base batch. Added input overhead can outweigh RP savings; report attempted input estimates, provider usage where returned, optional questions, final-scan applied count and removed characters separately.
     
Full-text admission, native keyword recursion, protection, book/world/Jev ceilings and ranking are evaluated first. Only at final WORLDINFO_SCAN_DONE is the activation map entry replaced by a copy with the validated extract, and only when the actual forced key and exact unchanged full source match. No extra entries admitted with freed space, no persistent writes, no changes to native activation or recursion. If the source was edited or transformed, stay full. The optional STWII key receipt is unchanged; a viewer must not infer actual excerpt text or tokens from that receipt. A separate versioned optional measurement contract may be considered after host evidence; do not modify STWII or Memory Books.
     
Validation: synthetic automated tests cover default/limits/custom, protected entry, unchanged binary questions, batch limits, low/missing/invalid selection, exact source checks, full budget, size rejection to full, final scan copy, and no extra successful request. Live ST payload, original file hashes, actual Jev decisions/usage, total cost, mobile/desktop UI and language quality are still adoption gates. Compare full against partial with identical candidates/model/profile and predeclared facts including cause/result, actors, knowledge boundaries, promises, habits, and exact quoted details. If any necessary fact is lost, stay full; do not release or merge on mock tests alone.

## Shared-source experiment follow-up

Previously the full Scene appeared in both primary and excerpt questions; the actual isolated fixture showed 1,560→2,924 estimated plan tokens. The new optional transport places a full numbered source once in the shared request state and both independent questions reference that named source. Binary include/skip options and score parsing are preserved; primary question wording and context placement change only when an excerpt question is attached, so real-model equivalence must be tested. Every original question's full input limit is rechecked against the expanded shared state. Batch count is unchanged; original base remains the fallback. A local conservative gate requires the added estimated input to be lower than the smallest estimated saving among offered excerpts. This is NOT a provider cost or measured savings guarantee; if no option clears the gate, no excerpt question is sent. Only index sets are retained for excerpt choices, and selected text is materialized when needed. See NanoGPT's model/API docs (https://nano-gpt.com/models/decisions/typesafe/jev-1.14) and TypeSafe's shared-state question description. Actual provider quality/usage, total cost, and ST payload replay remain adoption gates.

Cost-gate refinement: the planner removes only individual excerpt alternatives that fail the local cost/limit gate; it always offers full and never forces an aggressive excerpt. If none remain, it sends the unchanged binary request. Paragraph-local estimates compute candidate savings without repeatedly constructing/token-estimating full excerpts; the exact chosen extract is still rendered from original paragraphs. Potential savings assume an excerpt is accepted and actually applied; if Jev chooses full or skip, overhead remains. This is why real-model usage and end-to-end quality still gate adoption.
